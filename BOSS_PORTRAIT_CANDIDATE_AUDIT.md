## Permission blockers and steps that actually unblock publication

1. Obtain written approval from the rights holder that covers hosting or embedding named boss artwork **on this specific website**, including any future advertising use, display on the directory and detail page, resizing, and requested attribution.
2. Obtain any separate authorization necessary from the third-party image capture owner or source site, where applicable. Do not treat the pbz.gg label or Wikily links as licenses.
3. Check the exact game character and encounter variant visually, especially Zuo Shang prologue/finale, The Hunt's encounters, Yucong variants, Red + Seven-Stars, Meng Hua/Leng Tu, and Soulclaimer's similar appearance to other wardens.
4. Once approved, convert the original **authorized** file into a crisp WebP/AVIF, preserve its aspect ratio, place it under `public/bosses/` and fill `approvedBossImages` in `src/boss-images.js` with source, permission proof, license, dimensions and alt text.
5. Run the unit, production-build, browser and live SHA checks before publishing.

See [BOSS_PORTRAIT_RIGHTS_REQUEST.md](BOSS_PORTRAIT_RIGHTS_REQUEST.md) for a precise request to S-GAME. **The draft is not sent**, and a pending request is not permission.
