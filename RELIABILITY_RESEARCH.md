# Two-track guide reliability program

## Research agent — source verification
Research references are leads, **not endorsements or independent proof**. A page or video title alone does not validate a game mechanic. Do not reproduce guide text or screenshots without permission.

| Publisher | Pattern to study | Applied product rule |
| --- | --- | --- |
| PowerPyx | Chronological numbered collectibles, region totals | Preserve original source order and show selected-route coverage separately from reported totals |
| KeenGamer | Pre-boss missable warnings and tale starting points | Put critical checkpoints above collectible lists; show tale starting bell and consequence |
| GamesRadar | Dedicated quest walkthroughs | Each high-risk tale needs prerequisites, starting location, action, success check and cutoff |
| Power Up Gaming | Mystery quests and ending dependencies | Spoiler-gate ending explanations while leaving spoiler-light missable warnings visible |
| GameRiv | Start-here guide hub and nearest checkpoint | Show next unfinished action from saved progress and identify its closest known checkpoint |
| Oslink | Bosses in story order with chapter and location | Keep boss route order and named nearest bell |
| Ludo.guide | Numbered steps and community-verified labels | Number steps; never show a community-verified label without recorded player evidence |

### Evidence labels
- **Source-documented**: attributed written guide supports a route; may be outdated.
- **Video-indexed**: a named timestamp or chapter supports identification, but frames were not independently reviewed.
- **Gameplay-verified**: actual gameplay was reviewed or tested, with recorded proof and version.
- **Community-verified**: two or more independent player reports agree and links, dates and versions are recorded.
- **Unverified**: no adequate supporting evidence. Never elevate this based on popularity alone.

### Research acceptance record
For each high-risk quest, record region, quest, prerequisite, closest bell, deadline trigger, observable success condition, source URLs, timestamp (if available), game version, conflict notes, confidence and review date.

## Implementation agent — product changes
- Static route pre-rendering with working deep links.
- Region pages show chronological numbered collectible routes, reported vs indexed counts and confidence.
- Weeping Creek boss and tale panels use source-based nearest bells and item anchors.
- Home page recommends the next unfinished saved-progress action.
- JSON backup and merge restore.
- Late-game directions and endings behind spoiler disclosure controls.
- Source-linked item art only where a matching image is identified.

## Remaining blockers for full release
- Automated build and browser tests must pass on the current commit.
- Source claims and deadlines need independent gameplay review.
- Coverage beyond Weeping Creek is partial.
- Community-verified status requires actual linked community evidence.
- Third-party imagery requires appropriate reuse permission.

**Editorial rule:** No amount of site polish upgrades research to gameplay verification.
